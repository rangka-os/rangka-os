# S8a Money Field Type Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `money {currency_field}` field type in the kernel: exact decimals stored as `numeric(20,4)`, an IDR `bigint` twin `<field>_idr` at the document's rate, CEL arithmetic, Go + Python validator support, and a string JSON shape.

**Architecture:** A new `kernel/internal/money` package holds a fixed-scale (4 dp) `big.Int` decimal. `cel`, `store` and `engine` use it: CEL gets a `money.Decimal` value type, the store maps it to `numeric(20,4)` (read back as text), the engine rounds IDR values while computing and fills the twins after compute. The registry and both validators synthesise the twin field so every consumer sees `<field>_idr` as a read-only `currency` field.

**Tech Stack:** Go 1.24 (`math/big`, no new modules), PostgreSQL 16, Python 3 reference validator, JSON Schema 2020-12.

**Spec:** `docs/contracts/0013-money-and-currency.md` (the rulings), within `docs/superpowers/specs/2026-11-03-first-pilots-design.md` and `docs/superpowers/plans/2026-11-03-pilot-program.md` (stream S8a).

## Global Constraints

- IDR amounts are integers (whole rupiah); foreign-currency amounts are decimal strings with the ISO code; never float.
- Money is never decided by an LLM.
- Rounding is half away from zero everywhere (twin, IDR computes, `*`, `/`, `round`).
- Schema additions go in `schema/0.5/model.json` (contract 0013 §7), then `make -C kernel sync-schemas`.
- `make -C kernel test` and `make -C kernel compare-python` stay green. Go and Python validators print identical reports.
- Code, comments, docs in English; user-facing messages Bahasa Indonesia, sentence case, "kamu".
- No new Go module dependencies (the kernel still uses in-tree stand-ins).
- Environment notes for this worktree: run compare-python with `APPS=$(cd ../../../../rangka-apps/apps && pwd)` style absolute paths
  (`APPS`, `SITE`, `CONN` make vars) and a Python that has `jsonschema` + `pyyaml` on `PATH`. `internal/server` tests copy
  `rangka-connectors` with `cp -r`, which copies the worktree symlink; run them with `go test -overlay` of a `cp -RL`
  copy of `server_test.go` rather than editing it (pre-existing, not this stream's change).

## Review Focus

- **USD 1250.5 at rate 15873.5** → twin `19849812` (19,849,811.75 rounds up); **USD 0.5 at rate 3** → `2`; **-0.5 at rate 3** → `-2` (away from zero, not banker's). Test in Task 1 and Task 5.
- **Header twin vs line twins:** two lines USD 0.25 each at rate 3 → line twins `1` and `1`, header total `"0.5"`, header twin `2`; the header twin comes from the header amount. Test in Task 5.
- **Switching a document from USD to IDR** with fractional computed amounts: computed money values become whole rupiah, twins equal the amounts. Test in Task 5.
- **A JSON number with float noise** (`0.1` sent as a number) stores exactly `"0.1"`; a string with 5 decimals is refused with `bad_value`. Test in Task 4.
- **A USD document without a rate** fails save with `missing_rate`; the twin is never silently 0. Test in Task 5.

### Task 1: `money` package (exact decimal)

**Files:**
- Create: `kernel/internal/money/money.go`
- Test: `kernel/internal/money/money_test.go`

**Interfaces:**
- Produces (all in package `money`):
  - `type Decimal struct{ u *big.Int }` — value = u / 10⁴; the zero value is 0 (nil `u` means 0).
  - `const Scale = 4`
  - `func Parse(s string) (Decimal, error)` — strict: optional `-`, digits, optional `.` + 1–4 digits; surrounding spaces trimmed; `""` → error; at most 16 integer digits; no exponent, no `+`.
  - `func FromInt(n int64) Decimal`
  - `func FromFloat(f float64) (Decimal, error)` — via `strconv.FormatFloat(f, 'f', -1, 64)` then `Parse` (so >4 dp errors, NaN/Inf error).
  - `func Rat(v any) (*big.Rat, bool)` — exact rational of `Decimal`, `int64`, `int`, `float64` (shortest decimal form), `string` (decimal); false otherwise.
  - `func FromRat(r *big.Rat) (Decimal, error)` — rounds half away from zero to 4 dp; error when out of range.
  - Methods: `String() string` (canonical: no exponent, no trailing zeros after the point, no trailing point, `"0"` for zero, `"-0.5"`), `MarshalJSON() ([]byte, error)` (quoted `String()`), `Add(Decimal) Decimal`, `Sub(Decimal) Decimal`, `Neg() Decimal`, `Cmp(Decimal) int`, `Sign() int`, `IsZero() bool`, `IsWhole() bool`, `Round(places int) Decimal` (0–4, half away from zero), `Rat() *big.Rat`.
  - `func InRange(d Decimal) bool` — |d| ≤ 9999999999999999.9999 (numeric(20,4)).
  - `func ToIDR(amount Decimal, rate *big.Rat) (int64, error)` — round(amount × rate) half away from zero; error when it does not fit int64.
  - `func IsIDR(code string) bool` — `code == "" || code == "IDR"`.
  - `func ValidCode(code string) bool` — `""` or `^[A-Z]{3}$`.
