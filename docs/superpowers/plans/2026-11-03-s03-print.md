# S3 Print Formats Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Any model can be printed as an Indonesian business document (HTML, PDF when Chromium is present) from `.rk` print formats and a site letterhead, with exact money/date/terbilang helpers and the print permission enforced.

**Architecture:** `meta` loads kinds `print` (module/app and site `print/*.rk`) and `letterhead` (site) and validates them; a new package `internal/docprint` holds the helpers, the renderer (Go `html/template` wrapped in a kernel page shell), the permission check and the Chromium PDF call; `api` adds `GET /api/v1/r/{model}/{name}/print` and lists formats in `/meta`. Reference layouts live in `rangka-os/templates/print/`.

**Tech Stack:** Go 1.24 stdlib only (`html/template`, `os/exec`, `embed`), JSON Schema 2020-12 (in-tree validator), PostgreSQL 16 for server tests.

**Spec:** `docs/contracts/0008-print-formats.md` (the contract is the spec for this stream), with `docs/superpowers/specs/2026-11-03-first-pilots-design.md` and stream S3 of `docs/superpowers/plans/2026-11-03-pilot-program.md`.

## Global Constraints

- Work only in this worktree, branch `pilot/s03-print`; small commits; PR to `main`, never merge.
- Kernel has no third-party Go modules; use the stdlib only.
- Code, comments, docs in English. UI text Bahasa Indonesia first, sentence case, "kamu"/"Anda" in documents as customary; rupiah `Rp 1.250.000`; dates `27 Okt 2026`.
- IDR amounts are whole rupiah; never format money through float64 when the input is a decimal string (parse with `math/big` or integer arithmetic).
- No real customer data: fixtures use `PT Contoh Jasa Teknik`, `PT Pelanggan Contoh`, NPWP `00.000.000.0-000.000`, domain `contoh.test`.
- `.rk` files: strict YAML, first line `# yaml-language-server: $schema=https://rangka-os.github.io/rangka-os/schema/0.5/<kind>.json` for new kinds.
- Keep green: `make -C kernel test-unit`, `make -C kernel vet`, `make -C kernel test` (needs Postgres binaries), `make -C kernel compare-python`.
- Do not edit `schema/0.4/*.json`, `tools/rangka_validate.py`, or engine permission code (S1 owns general permissions).

## Review Focus

- **A record field containing HTML or `<script>`** (customer name `<b>PT</b>`): printed escaped; the response carries the CSP header. Test in Task 7.
- **A template path like `../../system.rk` or an absolute path**: refused at validate (`template_outside`) and never read at render. Test in Task 2.
- **Money as decimal string, float64 and int64 for the same value** (`"1250000.00"`, `1250000.0`, `int64(1250000)`): identical `rupiah` output; `"0.5"` rounds to `Rp 1`, `"-0.5"` to `-Rp 1`. Test in Task 3.
- **A user without a print-permitted role, and a record of another org**: 403 `permission_denied` with `model`/`action`, and 404 respectively; neither leaks HTML. Test in Task 7.
- **Chromium missing or hanging**: `as=pdf` returns 501 `pdf_unavailable` with a hint, and a hung Chromium is killed after 30 s. Test in Task 6 (missing) and code review (timeout).

Every model field missing from `Doc` (and from each child row, using `Children[field.Of]`) is set to `""`.
