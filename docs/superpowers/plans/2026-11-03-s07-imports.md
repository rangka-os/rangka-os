# S7 Imports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kind `import` + CSV/XLSX upload → preview (dry run) → commit in one transaction, with file- and row-level duplicate detection, so a Moka "Export Item Details" file becomes `outlet_sales` drafts.

**Architecture:** `meta` parses and validates `imports/<name>.rk` (Go and Python, identical reports). A new package `kernel/internal/imports` reads files into a header→cell table, maps rows to record inputs (columns, `=CEL`, link `match`), and owns the import log (`rk_imports`, `rk_import_keys`). Records are created through a new `engine.CreateMany` that runs many creates in one engine transaction, either committed or rolled back (dry run). REST handlers in `kernel/internal/api/imports.go`.

**Tech Stack:** Go 1.24 kernel, PostgreSQL 16, `github.com/xuri/excelize/v2 v2.9.1` (first real dependency; the module proxy is reachable), Python validator `tools/rangka_validate.py`.

**Spec:** `docs/contracts/0012-imports.md` (this branch); program plan `docs/superpowers/plans/2026-11-03-pilot-program.md` stream S7.

## Global Constraints

- Work only in this worktree, branch `pilot/s07-imports`; small commits; PR to `main`, do not merge.
- Code, comments, docs in English; every user-facing message (row errors, API messages) in Bahasa Indonesia, sentence case, "kamu".
- `.rk` is strict YAML; first line `# yaml-language-server: $schema=https://rangka-os.github.io/rangka-os/schema/0.5/import.json`.
- IDR amounts are integers (whole rupiah); never float for money.
- `make -C kernel test` (needs Postgres 16 binaries) and `make -C kernel compare-python` stay green; `make -C kernel vet` clean (gofmt).
- No real customer data: the Moka sample is synthetic (`kernel/internal/imports/testdata/moka-item-details.csv`, already committed with Task 4).
- Shared files other streams also touch (`store/system.sql`, `api/server.go` routes, `meta/registry.go`, `schema/schema.go`, `go.mod`): append, don't reorder, keep diffs minimal.

## Review Focus

- **Same Moka file uploaded twice:** second preview returns `duplicate: true`, commit 409 `already_imported`, record count unchanged. Test in Task 9.
- **Overlapping export (yesterday's file plus today's rows):** already-imported rows counted in `skipped`, only new rows created. Test in Task 9.
- **Two commits of the same preview, or two previews of the same file committed one after another:** the second commit gets 409; the unique index on `rk_import_keys` guarantees no duplicate even under a race. Test in Task 8.
- **Indonesian number formats and Excel serial dates** (`1.250.000`, `Rp 50.000`, `45963`): parsed to the same values as plain CSV. Test in Task 5.
- **A file whose header lacks a mapped column, or a CSV saved by Indonesian Excel (`;` delimiter, BOM):** clear error at the header row / reads correctly. Tests in Tasks 4 and 6.

### Task 5: Cell conversion

**Files:**
- Create: `kernel/internal/imports/convert.go`, `kernel/internal/imports/convert_test.go`

**Interfaces:**
- Produces: `func Convert(f *meta.Field, column, cell string) (any, string)` — value for the engine input and an Indonesian error message ("" when fine). Empty cell → `nil, ""`. By `f.Type`:
  - `int`, `currency` (and any integer money type): number → `int64`; fractional part ≠ 0 → `Kolom "%s" harus rupiah bulat, isinya "%s"` (currency) / `Kolom "%s" harus bilangan bulat, isinya "%s"` (int);
  - `float`, `percent`, `decimal` and other numeric: decimal string normalised to `123.45` (string, never float64) — the engine's `Coerce` takes it;
  - `date`: `dd/mm/yyyy`, `d/m/yyyy`, `yyyy-mm-dd`, Excel serial (integer 1–2958465, epoch 1899-12-30) → `"2026-11-02"`; else `Kolom "%s" harus tanggal (dd/mm/yyyy), isinya "%s"`;
  - `datetime`: same dates plus optional ` HH:MM[:SS]`; `check`: `1/0/ya/tidak/true/false/y/n` (case-insensitive) → bool, else `Kolom "%s" harus ya atau tidak, isinya "%s"`;
  - everything else (data, text, select, link…): the trimmed string.
  - Number grammar (helper `parseNumber(s) (intPart, frac string, ok bool)`): strip `Rp`/`IDR` prefix and spaces; optional leading `-` or `(…)`; `^\d{1,3}(\.\d{3})+(,\d+)?$` Indonesian, `^\d{1,3}(,\d{3})+(\.\d+)?$` English, `^\d+([.,]\d+)?$` plain (a single `,` or `.` is the decimal mark). Not a number → `Kolom "%s" harus angka, isinya "%s"`.

### Task 6: Row mapping

**Files:**
- Create: `kernel/internal/imports/mapper.go`, `kernel/internal/imports/mapper_test.go`

**Interfaces:**

- Produces:
```go
type RowError struct{ Row int `json:"row"`; Column string `json:"column"`; Message string `json:"message"` }
type Lookup interface{ // resolves link values inside the caller's org
    Find(model, field, value string) ([]string, error) // names whose field == value; field "name" = by name
}
type Planned struct{ Input map[string]any; Rows []int; Keys []string } // Keys: one hash per source row (hex SHA-256 of key cells joined by "\x1f"), empty when imp.Key is nil
type Mapping struct{ Records []Planned; Errors []RowError }
func Map(reg *meta.Registry, imp *meta.Import, t *Table, scope map[string]any, lk Lookup, now time.Time) *Mapping
```
  `scope` holds fixed parent values (`{"outlet": "OUT-01"}` for `per: outlet`). Order: header check first — every Column referenced in map/lines.map/key/group that is not a header → `RowError{Row: t.HeaderRow, Column: c, Message: `Kolom "c" tidak ada di file`}` and return without rows. Then group rows by `Group` column values in first-seen order (no `Group`: one record per row). Parent fields from the group's first row; each row → one line in `Input[lines.Field]` when `Lines` is set. Link fields: `Match` set → `lk.Find(target, match, v)`: 0 → `%s dengan %s "%s" tidak ditemukan` (target model label `id`, else model name; match field label lowercased, else field name), >1 → `%s dengan %s "%s" lebih dari satu`; no `Match` → `lk.Find(target, "name", v)`, 0 → `%s "%s" tidak ditemukan`. CEL failure → `Rumus untuk %s gagal: %s`; CEL results go through `Convert` as `fmt.Sprint(value)` (ints stay ints). Same key twice in the file → error on the later row, column = first key column, `Baris ganda: sama dengan baris %d`. A record with any row error is still returned (so preview shows it) but its rows carry errors.
