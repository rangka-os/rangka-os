# S4 Number Schemes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Number series in `config.rk` (`{pattern, reset}`), tokens `{YYYY} {YY} {MM} {ORG} {#…}`, gap-free per org+series at submit, models referencing `naming: {series}`, with every v0 string `naming` working as before.

**Architecture:** Pure pattern logic (render, period, default reset) in `kernel/internal/store/numbering.go`; a counter table `rk_number_series` incremented with `insert … on conflict do update` inside the document's transaction (row lock = queue, rollback = no gap); the engine resolves which scheme a model uses (contract 0009 §3) in one helper used by create, submit and seed. Validator rules land in Go and Python identically.

**Tech Stack:** Go 1.24 kernel, PostgreSQL 16+, JSON Schema 2020-12, Python reference validator (`tools/rangka_validate.py`).

**Spec:** `docs/contracts/0009-number-schemes.md` (this branch); program plan `docs/superpowers/plans/2026-11-03-pilot-program.md` stream S4.

## Review Focus

- **Concurrent submits of the same series** (20 at once): all succeed, numbers 1..20 unique, no gap. Test in Task 3 and Task 4.
- **A submit that fails after taking a number** (rolled-back tx): the next submit reuses that number. Test in Task 3.
- **Month boundary** (30 Oct → 2 Nov, site timezone Asia/Jakarta): monthly series restarts at 1, yearly continues. Test in Task 3 (store) and Task 4 (engine).
- **Opening data already carrying real numbers** (`INV/KOPI-SENJA/2610/0007` imported): next number is `0008`. Test in Task 3.
- **Pattern whose counter is not last** (`{####}/INV/{YY}`) and a counter that outgrows its width (`{##}` → `100`): renders correctly, continuation still parses. Test in Task 2 and Task 3.

- Produces:
  ```go
  // Scheme is how a model's documents are numbered.
  type Scheme struct {
      Series  string // "" = legacy prefix counter (rk_naming)
      Pattern string
      Reset   string // yearly | monthly | never; "" = DefaultReset(Pattern)
  }
  func DefaultReset(pattern string) string                 // monthly if {MM}; yearly if {YY}/{YYYY}; else never
  func Period(reset string, now time.Time) string          // never → "", yearly → "2026", monthly → "2026-11"
  func RenderSeries(pattern, orgCode string, now time.Time) (prefix, suffix string, digits int)
  func FormatNumber(prefix, suffix string, digits int, n int64) string // zero-pad to digits; never truncate
  ```
  `RenderSeries` replaces date tokens and `{ORG}`, splits at the single `{#…}` (pattern is validated; if no counter, treat as counter at end with 4 digits like `ExpandPattern`).

- Produces:

  ```go
  // OrgCode is the org's short code for {ORG}: rk_orgs.code when set, else the org id upper-cased.
  func OrgCode(ctx context.Context, q pg.Querier, org string) (string, error)
  // NextSeriesName takes the next number of a series for an org inside q's transaction. tables are the record
  // tables of every model using the series; the first number of a period continues after the highest existing

  func NextSeriesName(ctx context.Context, q pg.Querier, org string, s Scheme, tables []string, now time.Time) (string, error)
  ```
- SQL added to `system.sql`:
  ```sql
  create table if not exists rk_number_series (
    org_id text not null,
    series text not null,
    period text not null,                 -- '' (never), 2026 (yearly), 2026-11 (monthly)
    last   bigint not null,
    primary key (org_id, series, period)
  );
  alter table rk_orgs add column if not exists code text;   -- {ORG} in number series (contract 0009)
  ```
- Allocation: one statement `insert into rk_number_series … values ($1,$2,$3, coalesce((select max(n) from (<union over tables of substring(name from $re)::bigint where org_id=$1 and name ~ $re>) x),0)+1) on conflict (org_id, series, period) do update set last = rk_number_series.last + 1 returning last`, with `$re = '^' + regexp.QuoteMeta(prefix) + '([0-9]{1,18})' + regexp.QuoteMeta(suffix) + '$'`; tables quoted with `pg.QuoteIdent`; empty `tables` → `0`. `now` is already in the site timezone (caller's job).
